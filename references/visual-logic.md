# 图形语义与典型问题

## 核心概念的可识别性

从半外行评审视角检查：暂时不读细字，是否仍能辨认图的核心研究对象或方法？最醒目的元素是否对应本项目重点？

智能体案例中，只有“分析—检索—结论”的专业流程不足以让人立即识别 agent。醒目的机器人结合“大语言模型”“任务规划”“工具调用”“结果归纳”建立了身份与功能。机器人是核心概念的识别符号，不是装饰物，也不能代替真实工作流程。

其他项目应选相应的生物对象、器件、过程或模型视觉中心。不要强制每图增加机器人，不把所有方法画成神经网络，不为了“智能”加入未在方案中出现的 AI 模块。

## 流程与并行工具

为每个框说明它是输入、处理、资源、结果还是局部说明，再确定箭头含义。颜色和位置不能替代实际连接。

- 并行工具应有明确的共同调度及结果汇总，不能只连到第一个工具、再从最后一个工具出去，造成串行误读。
- 结果归纳所用的模型结果、区域注释、公共证据应能追溯到对应来源。
- 同一个框内不把多个无关系的块摆在底部，靠向下展开强行制造意义。
- 缩短术语后重新核对含义：公共资源核验不等于新的实验验证，候选区域不等于已证实因果位点。

## 局部放大与展开色带

可借鉴参考中的 embedding/token 到细节或 loss 模块的展开形式，但只迁移**局部—详解**的关系，不自动迁移损失函数或模型结构。

合格的展开带具备：

1. 窄端明确贴合主图内真实存在且有语义的对象，例如工具卡片、表示向量或某个结构区域。
2. 宽端对应该对象的详解模块；标题、主题色与科学内容一致。
3. 源节点与详解按相同顺序排列，展开带不交叉、不遮住文字及关键连接。
4. 使用浅色、通常无边线的窄到宽多边形，置于主要内容后方；保持白色详解面板。
5. 展开带表示视图关系，流程箭头表示信息传递，两者不能混为一谈。

**失败模式：** 在模型框底部增加几个独立色块，仅为了向下引出内容。这些“贴地板色块”不属于流程，评审无法理解其作用。修正时应把起点改为真实节点，必要时重排主框、详解与右侧面板，不继续强塞进旧框架。

## 干预前后与变化图形

当图中明确设置扰动、治疗、状态转移等前后状态或响应结果对照时，小图必须与所表达的变化一致。仅展示拟开展的处理与测量流程时，不要求画出效应，更不能因出现“药物处理”等节点就编造药效。无变化、弱变化等真实结论也须忠实保留。

- 不得用相同的群体图分别标“初始”和“预测”冒充响应。示意群体可改变组成、分布或状态位置，但保持类别身份一致。仅等比放大同一图往往不足以表示组成变化。
- 变化要明显到能支撑概念表达，又不能被误认为定量实验结论。修改的是概念示意时，在备注/图注说明；图内保留“预测状态”等必要限定。
- 可及性等前后曲线使用相同横坐标对应位置，体现可辨认的升高/降低；同一高亮区域对齐。使用适合数据含义的平滑峰形与局部填充，避免不必要的锯齿折线。
- 真实数据必须尊重实际差异。若真实效应很小，不得为满足“变化明显”而夸大、编造峰形或修改坐标误导读者；可合理放大局部并保留尺度。
- 图中的矩阵变化、颜色、峰图变化与标签相互一致。用图形承担解释，但不凭空添入模型已能实现的功能。

## 自我改进与反馈闭环

此例采用四个四字标签、等大框、2 × 2 对齐：

`反馈归因 → 策略迭代 → 策略执行 → 任务评价 → 反馈归因`

按科学含义而不是视觉顺手排列闭环。入口与回流对象应清楚，不能让箭头在无关位置终止。在该案例中，改进对象为分析执行策略与改进策略，不表示智能体自动重训或改写基础模型。

四字节点适合紧凑反馈结构，但不能为凑四字改坏术语。其他项目按实际节点数和过程关系布局。闭环信息较少时采用紧凑面板，不放大四个空框去追求与结果面板各占一半。

## 素材完整与语义忠实

优先使用用户示例中合适的完整细胞或群体素材。若源文件存在可编辑组合，提取原组合通常比从截图裁切更可靠。检查外轮廓、触角、膜边缘、透明边界与长宽比。

复用科学结果面板时保留必要轴、图例、标签和语境，不把它当任意装饰素材。可以重排纯示意资产来表达新概念，但必须区分于原图的实测结果。修改局部图后重新检查整图配色与意义，避免出现“左边是初始蓝色，右边却把蓝色当预测”等矛盾。
