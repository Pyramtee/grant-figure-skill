# 排版与配色细则

## 参考图学习

先观察完整画面，再检查核心区和小图细节。分别记录：

| 维度 | 需要判断的内容 |
| --- | --- |
| 第一眼识别 | 核心对象是否立即可认；最大或最醒目的元素是否对应研究重点 |
| 信息组织 | 主流程方向、模块面积、主次比例、并行与局部详解关系 |
| 密度 | 图形与文字比例、模块内部空白、外边距与通道宽度 |
| 字体 | 中文/英文、字号层级、字重、同行基线与标题对齐 |
| 框线 | 轮廓颜色、主框与内部线的粗细、箭头头型、实虚线用途 |
| 配色 | 具体色值、局部填色范围、颜色与对象的对应关系 |
| 素材 | 二维图形语言、完整轮廓、细胞/模型/数据等元素的画法 |

能读原生对象就提取色值和线宽；否则可从参考图取色。只读参考文字或挑几种近似颜色不足以复现审美。用户后来的明确要求优先于参考中不一致的细节，例如原始参考包含解释句和 a/b/c，而本风格默认删去这些内容。

## 文字与字号

### 标签语体

用名词性术语标记对象、过程或产物。过程名词如“任务规划”“证据核验”“策略迭代”“细胞分选”“药物处理”可以使用。判断它是否在命名一个过程，不机械判断术语内部是否含有动词；但不要把“比较细胞状态”这类动宾短语缩短几个字就当作合格标签。

| 不采用 | 可采用，需符合真实内容 |
| --- | --- |
| 比较细胞状态 | 细胞状态差异 |
| 识别候选区域 | 候选调控区域 |
| 根据中间结果调整任务 | 任务反馈 / 策略迭代 |
| 初始细胞状态（scATAC） | 初始细胞状态 |
| 公共数据核验＋下面一行解释句 | 公共证据核验＋数据库/证据关系小图 |

不要机械禁用 scATAC 等技术术语：仅在它对当前层级的理解确有作用时作为独立术语保留。公式、数据单位与必要科学符号不受“不得括号解释”的机械替换影响，原始结果标签也不能被错误改写。长解释移到备注；必要的“预测”“候选”等限定保留在图内。

### 字体规则

- 中文默认黑体；macOS 使用实际可用的 `Heiti SC`，其他环境可用 `SimHei`。确认字体可用；确需替代时记录并说明，不悄悄换成宋体、苹方或系统默认字体。
- 英文、数字默认 `Arial`。中英混排按文字片段分别设定，不只改文本框默认字体；检查导出后的 East Asian/Latin 字体声明与实际渲染。
- 最多三档字号：主标题、模块标题、内部标签。必要轴标和图例原则上归入内部标签档，不随意增加第四档。若需引用已有数据图，优先依据可编辑原文件在不改变科学含义的前提下统一标注。仅有位图而无法统一时，保留科学信息、评估可读性，并明确此项尚未满足；不能默认为豁免或宣称位图字体已经统一。
- 同级文字字号、字重一致。大部分内容加粗；获认可案例全部标签为粗体。仅极小的最低层标记可以常规字重，但不能以“次要”名义让整片模块文字变轻。
- 长标签先精简或调整模块宽度，必要时按术语边界换行，不使用局部自动缩小、挤压或一堆小字号。
- 文本色默认 `#111111` 或黑色；深色小标题底可用白色。低层标签也不靠彩色文字区分。

### 文字框与标题取舍

- 单行标签框按文字高度定高，尤其压缩上下内边距，让文字占据框内主要高度。可从“字号 30 px、框高约 38 px”的案例比例起稿，再按实际字形调整；不把这个数值套用到含图形的功能模块。
- 同级标签共用字号、框高和内边距。较长标签优先调整横向空间，不把所有短标签都拉成宽大的空卡片。
- 嵌入基金正文的单幅示意图，默认不另加跨全图主标题；保留用于识别核心对象的模块标题。用户或模板要求主标题时从其要求。
- 不习惯性追加收尾、总结或兜底功能块。只有承担本图必要、独立作用的内容才占一个模块，不能因正文提及就把它逐项搬进图里。

### 已验证尺寸基线

以下为 **1600 × 800 设计坐标、96 px/in** 的案例基线，不是固定输出尺寸。PNG 分辨率增加不等于字体物理尺寸增加。

| 层级 | 设计字号 | 相应 PPT 字号 | 字重 |
| --- | --- | --- | --- |
| 核心对象标题 | 32 px | 24 pt | 粗体 |
| 模块标题 | 26 px | 19.5 pt | 粗体 |
| 内部标签 | 22 px | 16.5 pt | 粗体 |

其他画布按整体比例调整三档，不能逐个文本框独立缩放。最终要放入基金正文时，按实际插入宽度检查可读性；若缩小后文字过密，先减少次要内容或重排，不靠高分辨率掩盖字号过小。

换算：`最终字号 pt = 设计字号 px ÷ 画布宽 px × 插入宽 mm ÷ 25.4 × 72`。例如 1600 px 宽画布插入 170 mm 宽正文，22 px 仅约 6.6 pt，30 px 约为 9.0 pt。需要正文阅读时，可从最终主要标签约 9 pt 起检查，并相应调整三档及布局；这不是所有基金的硬性字号标准，具体模板与实际可读性优先。获认可案例的坐标字号不能不经换算直接套用。

## 线条与框体

默认轮廓色为参考的深蓝黑 `#092A38`。深色线条提供清晰边界；避免大量浅灰、浅蓝、发虚的细轮廓。若用主题色框线，其对比度和粗细要保持清楚，不能与淡色填充混淆。

| 用途 | 1600 × 800 案例基线 | 使用方法 |
| --- | --- | --- |
| 核心主框 | 2.4 px / 1.8 pt | 强调主模型或主研究对象 |
| 常规模块外框 | 2.0 px / 1.5 pt | 同级模块统一 |
| 内框与分隔线 | 1.6–1.8 px / 1.2–1.35 pt | 选定少量档位，避免每框不同 |
| 主流程箭头 | 2.0–2.4 px / 1.5–1.8 pt | 一致头型、头部大小与端点间隙 |
| 数据曲线 | 约 2.1 px / 1.575 pt | 清晰且不盖过主流程 |
| 极细网格/微型结构 | 0.65–1.4 px | 仅矩阵格线、网络内部等最低层细节 |

数值用于起稿，最终看渲染效果。不能因参考源码注释与实际属性矛盾而照抄注释，应核对导出对象。

- 同级框的线宽、边角、标题条高度一致；参考以直角框为主，少量形状随实际对象变化。
- 连线居中接入相应边缘，不刺入文字，不贴着标签、不误触相邻模块；转折路径和间距保持规律。
- 实线一般表达主流程，虚线可表达反馈或次级关系，但必须全图语义一致。不要为了好看任意切换。
- 避免长距离交叉；通过节点排序、公共调度线或公共汇总线简化连接。逻辑图仍应能识别每个分支的输入和输出。
- 用共享坐标确定同排外框上下边界、标题条边界、箭头中心线与端点，不能只凭视觉逐个摆放。采用齐平的主图与两侧详解布局时，三者上下沿都要检查；其他构图不强求全部等高。
- 承载关键交互或主流程时，可优先采用 PPT 原生块状箭头；局部证据关系用短而直接的连接。只保留解释关系所需的连线，避免多条跨框长线与重复分支。
- 对话气泡优先采用原生标注形状，或一个连续闭合轮廓。不要用独立三角和矩形拼接后留下断口、重边或错位；导出后放大检查尾角与底边接缝。

## 图标取舍与素材一致性

图标用于辨认对象或理解操作，不是每个标签的必备前缀。研究人员、智能体、条件设置等概念可以借助清晰图标；文字已经明确的任务按钮不必再添微型图标。减少图标并不等于减少科学信息。

同图内的人物、机器人和控制图标应共享二维风格、描边强度、低饱和填色与细节密度。为小尺寸使用设计素材，既避免过细的简陋符号，也避免缩小后无法识别的细节。透明边距按可见主体检查，必要时通过原生裁切去除留白，保持轮廓完整与比例不变。

## 语义配色

先列“概念—颜色”映射，随后沿输入、主模块、局部详解与输出追踪。固定的是**语义一致性**，不是所有项目都必须用同一套生物学含义。

| 角色 | 获认可案例含义 | 主色 | 标题/局部底色 | 淡展开带 |
| --- | --- | --- | --- | --- |
| 蓝 | 初始状态、区域分析、智能体策略 | `#215F9A` | `#DCEAF7` | `#EBF3FB` |
| 橙/桃 | 干预条件、扰动预测与响应 | `#C04F15` | `#FBE3D6` | `#FCF0E9` |
| 紫 | 先验、公共资源与调控证据 | `#AA8DC6` | `#EBE4F1` | `#F3EFF7` |
| 深轮廓 | 框、连接与结构 | `#092A38` | — | — |
| 正文 | 所有文字 | `#111111` | — | — |

可用同主题色阶：蓝 `#FFFFFF / #DCEAF7 / #A6CAEC / #4E95D9 / #215F9A`；橙 `#FCF0E9 / #F6C6AD / #F2AA84 / #C04F15 / #663115`；紫辅色 `#D9CCE6`。这些用于示意矩阵、峰图与局部强调；真实数据图按其量纲和原始色标处理，不擅自换色改变解释。

落实到每一层：公共证据的工具图标、数据库、详解标题、输出标签均偏紫；干预输入、扰动工具、预测曲线均偏橙。不能出现初始矩阵橙色、预测矩阵蓝色，却在结果曲线中反过来。新图可增加协调的颜色区分新角色，不因沿用参考风格就强迫不同含义共用同一种颜色。

细胞群体的红/蓝/绿/黄表示**类别身份**，可与流程主题色并存。前后保持类别颜色相同；蓝色群体不自动等于“初始状态”。必要时用名词图例帮助区分，但不增加解释段落。

## 构图、密度与局部填色

- 白色主画布、白色主面板；标题条和关键节点使用少量淡底色。主体不是一块块大面积彩色卡片。允许有明确用途的色块强调，不能为了“克制”把重点全部去掉。
- 先给核心对象、主模型和核心关系足够面积；输入和辅助分析按信息量压缩。主次由尺寸、位置、粗体、结构和局部颜色共同建立。
- 外边距、同级间隔和内边距形成稳定节奏。获认可案例可从约 20 px 外边距及普通间隔、38–44 px 标题条起步；长箭头和展开带另留通道，不能为追求统一数值挤压语义。
- 大小相同的同级节点对齐；整块面板的面积按内容与作用分配。两块面板不必机械各占一半，否则容易出现一边拥挤、一边空旷。
- 内容量由本部分研究决定，允许少于参考图。空旷时依次检查框体是否过大、模块间距是否过长、画布是否过高；通过缩减版面恢复紧凑，不能强行补齐参考图的信息量。只有遗漏了必要科学内容时才补内容。
- 保留合理留白用于分组和读图；消除的是无作用的大空区，不是所有空白。
